## Backend
- `toLaporanPublik(row)` → bentuk `LaporanPublik` (`docs/API.md`). Query publik **tidak boleh** `SELECT` kolom `pengguna`.
- `GET /laporan/publik`: filter `kelompok` (menunggu → Menunggu Verifikasi; diproses → Terverifikasi+Diproses; selesai → Selesai), `wilayah` (`lokasi.wilayah`), `kategori`; hanya `STATUS_PUBLIK`; `ORDER BY tanggal_laporan DESC LIMIT/OFFSET`.
- `GET /laporan/publik/:id`: 404 bila status tidak publik (Ditolak/Perlu Revisi/Digabung).
- `GET /laporan/ringkasan`: tiga angka untuk O-0202.
- `GET /laporan/saya` & `/saya/:id`: filter `id_pelapor = req.pengguna.id`; detail menyertakan `catatanVerifikasi` (verifikasi terakhir) dan `riwayat` urut naik (`getRiwayatStatus`).
- `GET /notifikasi`, `PATCH /notifikasi/:id/dibaca` (hanya milik sendiri).

## Mobile
- **I-02 Beranda** (`BerandaScreen.js`): header logo + lonceng (O-0201, badge `belumDibaca`, ke `/warga/notifikasi`); kartu ringkasan (O-0202); tab Semua/Menunggu/Diproses/Selesai (O-0203); filter wilayah (UC04 alt 1, data dari `referensiApi`); kartu laporan (O-0204: kategori, waktu relatif, `judulLaporan()`, wilayah, foto, status, tombol Detail → `/warga/laporan/<id>?mode=publik`). Pull-to-refresh.
- **I-03 Detail** (`DetailLaporanScreen.js`): `useLocalSearchParams()` → `id`, `mode`. O-0301 header (`kodeLaporan`, `LencanaStatus`, kategori, tanggal), O-0302 foto (ketuk untuk perbesar — Modal), O-0303 lokasi + `PetaTampil`, O-0304 deskripsi, O-0305 riwayat **hanya mode saya**. Mode saya + status Perlu Revisi → tampilkan catatan admin + tombol **Revisi** → `/warga/revisi/<id>`.
- **Laporan Saya** (`LaporanSayaScreen.js`): daftar milik sendiri, ke detail `mode=saya`.
- **Notifikasi** (`NotifikasiScreen.js`): daftar, tandai dibaca saat ditekan, buka laporan terkait.
- Semua daftar: `TampilanMemuat`, `TampilanKosong` ("Belum ada laporan"), `TampilanGagal` ("Tolong muat ulang halaman" — otomatis setelah 5 detik oleh `api/client.js`).

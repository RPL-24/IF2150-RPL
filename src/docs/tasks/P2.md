## Backend
- `POST /laporan` → `buatLaporan(req, res)`:
  1. `periksa(skemaBuatLaporan, req.body)`; tolak 400 bila `req.file` kosong.
  2. `const foto = await cloudStorageAdapter.simpanFoto(req.file)`
  3. `const { wilayah, alamat } = await getWilayahFromCoordinates(lat, lng)`
  4. `withTransaction`: `cariAtauBuatFasilitas` → `simpanLaporan` (Q-001 + `jumlah_laporan + 1`) → `setLokasiLaporan` (Q-005, koordinat `"lat,lng"`) → `catatRiwayat(... 'Laporan berhasil diterima oleh sistem.')`.
  5. Balas 201 dengan DTO `LaporanSaya`.
- `cariAtauBuatFasilitas` (gap G1): kandidat = fasilitas kategori sama dalam kotak ±0,0005° lalu saring `jarakMeter <= ATURAN.RADIUS_FASILITAS_METER`; pilih terdekat; jika tidak ada → INSERT fasilitas baru (`nama = "<kategori> - <alamat>"`).
- `PUT /laporan/:id/revisi`: hanya pemilik (404 bila bukan), hanya status `Perlu Revisi` (409). Update field yang dikirim (foto baru, deskripsi, kategori, lokasi), lalu `ubahStatus(... 'Menunggu Verifikasi', 'Laporan direvisi oleh pelapor.')`.

## Mobile I-04 (`BuatLaporanScreen.js`)
Objek antarmuka DPPL Tabel 6.4:
- O-0401 foto: `expo-image-picker` (`launchCameraAsync` / `launchImageLibraryAsync`, kualitas 0.6), pratinjau gambar.
- O-0402 kategori: 4 pilihan dari `SEMUA_KATEGORI`.
- O-0403 peta: tombol **Gunakan Lokasi Saya** (`expo-location` `requestForegroundPermissionsAsync` + `getCurrentPositionAsync`) → `sumberLokasi = 'GPS'`; bila izin ditolak/GPS mati → pengguna ketuk/geser pin di `PetaPilih` → `'MANUAL'` (KF03).
- O-0404 deskripsi: maks `ATURAN.BATAS_DESKRIPSI` dengan penghitung `0/300`.
- O-0405 tombol **Kirim Laporan** terkunci sampai lengkap (UC01 normal langkah 2, alt 1). Teks bantu "Lengkapi foto, kategori, lokasi, dan deskripsi untuk melanjutkan".
- Sukses → `router.replace('/warga/laporan/<id>?mode=saya')` (UC01 langkah 3 "menampilkan informasi laporan").
- Mode revisi: rute `/warga/revisi/[id]` memakai komponen yang sama; ambil `useLocalSearchParams().id`, muat `wargaApi.detailSaya(id)` untuk prefill, kirim `laporanApi.revisi`.

## Test wajib (`server/tests/laporan-buat.test.js`)
- `validasiIsianFormulir`: lengkap → true; foto/deskripsi/koordinat kosong → false; deskripsi > 300 → false.
- `POST /laporan` sukses (pakai `.attach('foto', buffer, 'a.png')` supertest) → 201, status Menunggu Verifikasi, ada baris `lokasi` dan riwayat, `jumlah_laporan` bertambah.
- Titik < 30 m dari fasilitas seed berkategori sama → memakai fasilitas itu; kategori berbeda → fasilitas baru.
- Tanpa foto → 400; peran ADMIN → 403.
- Revisi laporan seed `Perlu Revisi` milik `warga2` → 200 + status Menunggu Verifikasi; laporan orang lain → 404.

## Backend
- `hitungSkor(db, idLaporan)` (Algo-009): kembalikan `null` bila belum ada baris `skor_prioritas`. `jumlahPelapor = 1 + COUNT(id_laporan_induk = id)` (Q-009), `lamaMenunggu = hari sejak tanggal_laporan` (bulatkan ke bawah), `frekuensiBerulang = Fasilitas.getJumlahLaporan(db, id_fasilitas)` (sudah ada dari starter), simpan (Q-010 + `dihitung_pada = NOW()`).
- `POST /admin/laporan/:id/verifikasi` → `Verifikasi.tetapkanKeputusan` dalam `withTransaction`:
  1. Pastikan status `Menunggu Verifikasi` (409 jika tidak) — `ubahStatus` sudah menolak transisi ilegal.
  2. `simpanVerifikasi` (Q-003).
  3. `Laporan.ubahStatus(db, { statusBaru: KEPUTUSAN_KE_STATUS[keputusan], deskripsi: '<keputusan>. Catatan: <catatan>', idPengguna: idAdmin })` (Algo-002, gap G2: tidak ada status "Disetujui", langsung Terverifikasi).
  4. Bila Disetujui: `buatSkorAwal` (Q-008) lalu `hitungSkor` (Algo-008 `teruskanKePemerintah`).
  5. `kirimNotifikasi` ke pelapor: `"Laporan #<id>: <keputusan>. <catatan>"` (KF07).
  KF08 "tahan laporan" otomatis: laporan yang belum Terverifikasi tidak masuk `STATUS_PRIORITAS`.
- `GET /admin/laporan/:id`: detail + `pratinjauSkor` (pakai `hitungNilaiSkor` dengan nilai saat ini, tanpa menyimpan) + riwayat + histori verifikasi.
- `GET /admin/laporan/jumlah-baru`: badge.

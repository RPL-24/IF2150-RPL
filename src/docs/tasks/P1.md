## Backend UC07
- `getKandidatDuplikat(db)`: semua laporan berstatus `STATUS_AKTIF`, join `lokasi`, `pengguna` (nama pelapor boleh untuk admin), `fasilitas`, `skor_prioritas`; kelompokkan per `id_fasilitas`; `kandidat = jumlah >= 2`; kelompok kandidat di atas. Bentuk respons: `docs/API.md#uc07`.
- `gabungLaporan(db, { idLaporanList, idAdmin })` (Algo-012, Q-013) dalam **satu transaksi**:
  1. Ambil semua laporan `FOR UPDATE`; tolak 409 bila ada yang tidak aktif, 400 bila kategori berbeda (G15).
  2. Induk = `tanggal_laporan` paling awal.
  3. Setiap anak: `Laporan.ubahStatus(db, { idLaporan, statusBaru: 'Digabung', deskripsi: 'Digabung ke laporan #<induk>', idPengguna: idAdmin, idLaporanInduk: induk })`, lalu `UPDATE laporan SET id_fasilitas = <fasilitas induk>`.
  4. `SkorPrioritas.hitungSkor(db, induk)` (stub P4 mengembalikan `null` sampai P4 selesai — tidak masalah).
  5. `Fasilitas.getJumlahLaporan(db, fasilitasInduk)` agar jumlah berulang ikut diperbarui.

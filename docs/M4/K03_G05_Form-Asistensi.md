### Catatan

| Catatan |
| --- |
| 1. Registration page ditulis dalam folder registration isinya file antarmuka  |
| 2. Di dalam front end registration page, kelas input field dinamain komponen dan button bisa dinamakan sebagai komponen biar bisa reusable. Registration page itu sebagai pembungkus, pake aggregation atau composition, soalnya pake hubungan HAS A. Kalau registration ilang, include fieldnya masih kepake gak? Engga kalau composition. Kalau aggregation, kelas”nya masih bermakna. |
| 3. Ada method yaitu fungsi dan prosedur yg dimiliki kelas, segala hal yg berhubungan untuk memodifikasi data melalui class |
| 4. Client n server harus ada penengah, misal perantara yang memberikan layanan buat validasi penyebaran data, misal registration controller. Yang validasi registration controllernya bukan registration page, hubungan mereka association. Regis page sama masyarakat tidak memiliki hubungan langsung. |

## Backend
- `GET /prioritas`: join `lokasi`, `skor_prioritas`, `fasilitas`; filter `kategori`, `wilayah`, `status`; `ORDER BY skor DESC` (Algo-005 diwujudkan di SQL, G14). Tanpa identitas pelapor (G9). KF17: sebelum query, hitung ulang skor yang `dihitung_pada` lebih tua dari 1 jam memakai `SkorPrioritas.hitungSkor` milik P4 (stub mengembalikan null — aman).
- `PATCH /laporan/:id/status`: `Laporan.ubahStatus(... status, keterangan, idPengguna)` dalam transaksi; balas `LaporanPrioritas`.
- `GET /fasilitas?q=&berulang=`: cari di `nama_fasilitas`, `lokasi_fasilitas`, `wilayah` (`ILIKE`); bila `q` diisi tapi kosong → `pesan = PESAN.FASILITAS_TIDAK_DITEMUKAN` (UC08 alt 1).
- `GET /fasilitas/berulang?limit=`: `kandidat_evaluasi = true` urut `jumlah_kerusakan_berulang DESC`.
- `GET /fasilitas/:id`: detail + laporan pada fasilitas + riwayat status semua laporannya terbaru dulu (KF23), tanpa identitas pelapor.
- (Stretch KNF05) `GET /prioritas?format=csv` → ekspor CSV untuk sistem pemda.

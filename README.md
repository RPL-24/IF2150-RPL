# LaporKota

Platform web pelaporan kerusakan infrastruktur publik di Kota Bandung: warga melapor dengan foto/video dan titik lokasi, Tim Administrasi memvalidasi dan mengevaluasi, Eksekutor Lapangan mengerjakan perbaikan. Tugas Besar IF2150 Rekayasa Perangkat Lunak, kelas K03 kelompok G07 "Siulan".

- **Production:** https://laporkota.vercel.app
- **Dokumentasi aplikasi (instalasi, menjalankan, akun uji, tim, tabel basis data): [`src/README.md`](src/README.md)**
